# 【お遊び】5つの軸でみる、わたしの女装傾向

30の質問に答えると、女装にまつわる「好き」や「居心地」を5つの軸で整理し、32タイプのうちの1つとレーダーグラフで表示する、ブラウザだけで動くオリジナル診断(試作版)です。

> **ご注意**
> 科学的に検証された心理検査でも、医学的な診断でもありません。性自認・性的指向・性格を判定・断定するものではありません。性的な内容の質問がふくまれます。結果の文章は「楽しみ方のヒント」であり、性格や行動の事実認定ではありません。

## 特徴

- 質問は30問(5軸 × 各軸6問)。出題順は開始のたびにランダムです。
- 5つの軸の判定から、5文字のコードと32タイプの名前・解説文を表示します。
- 5軸のレーダーグラフと、軸ごとの平均点を表示します。
- 回答はブラウザ内だけで集計します。サーバーへの送信や保存はしません(再読み込みで消えます)。
- 結果のコピーと共有は、利用者が操作したときだけ行います。

## 5つの軸

| 軸 | 内容 | 2つの側 |
|---|---|---|
| A | からだの性別らしさ、しっくり度 | C: いまのからだで安心 / T: ちょっと気になる・探りたい |
| N | 女性らしい見た目へのこだわり | B: こだわりゆるめ / F: とことん磨きたい |
| J | ひとりで満足? 反応もほしい? | P: ひとり満足派 / O: 反応も楽しみたい派 |
| G | 女性らしい自分のイメージと性的なドキドキ | I: つながり薄め / E: つながり濃いめ |
| H | 男としてのプレッシャー | A: 軽め / R: 重め |

結果コードは A・N・J・G・H の順に1文字ずつ並べた5文字です(例: TFOER)。タイプは2^5 = 32通りです。

## 採点のしくみ

- 各軸は、両側の質問が3問ずつです。
- 回答は5段階で、点数は 0 / 2 / 3 / 4 / 6 に換算します。両はしの回答(「ぜんぜん当てはまらない」「すごく当てはまる」)は、ほかより少し重く数えます。
- 両側の合計を比べ、高い側をその軸の結果とします。ぴったり同点の軸は X(判定おあずけ)とします。
- 同点ではなく、平均の差が0.6点未満の軸は「境界ぎみ」とします。0.6点は試作版の目安です。
- 同点の軸があるときは、32タイプに当てはめず、回答プロフィールとして表示します。
- レーダーグラフの値(0〜100)は、両側の平均の差を目盛りに直したものです。50は同点で、割合やパーセンタイルではありません。軸がちがうと、強さをそのまま比べることはできません。

## ファイル構成

- `index.html` … 診断本体(HTML・CSS・JavaScriptを1ファイルにまとめています)
- `icons/` … タイプごとのイラスト画像(`コード.png`、32枚)

## 使いかた

1. このリポジトリを開き、`index.html` をブラウザで開きます(ダウンロードしてそのまま開けます)。
2. 「さっそくスタート」を押して、30問に答えます。
3. 結果画面で、タイプ名・グラフ・解説文を確認します。

画像は `icons/` フォルダから読み込みます。`index.html` と `icons/` を同じ場所に置いてください。
